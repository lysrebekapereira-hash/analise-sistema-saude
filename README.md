## Sistema de Agendamento de Consulta - Espercificação de Requequisitos 

## 1.Visão Geral 
Este documentos especifica os requisitos funcionais e não funcionais do módulo de agendamenti.

##2. Requisitos funcionais (RF)
- [ ] RF01: O paciente deve conseguir visualizar os horários dispoíniveis de cada médico.
- [ ] RF02: O sistema deve permiitir o agendamento de consultas com confirmação porv e-mail.
- [ ] RF03: O médico deve visuakizar sua agenda díaria e semenal.

## 3. Rquisitos Não Funcionais (RNF)
- RNF01 (Desempenho): O tempo  de resposta para busca de horário não deve exceder 2 segundos.
- RNF02 (Segurançã): Dados sensíveis da saúde devem estar em conformidade com a LGPO.
